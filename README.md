# ❄️ Snowball AI Learning: Derzkiy Snegovik

**Образовательная 3D-игра для изучения турецкого языка (по учебнику Yeni İstanbul A2).**

### 🎮 О игре:
Ты оказываешься на заснеженной детской площадке. Твоя задача — вставлять пропущенные слова в предложения, кидая снежки в снеговиков. 

### 🧊 Особенности:
* **Персонажи:** Снеговики-подростки с дерзким характером и «уставшим» взглядом.
* **Геймплей:** Вид от первого лица (видны руки героя).
* **AI (ИИ):** Встроенный интеллект адаптирует сложность и придумывает новые фразы, если задания из учебника закончатся.
* **Атмосфера:** Падающий снег, мультяшные здания и стилизованный дизайн.

### 🛠 Технологии:
- **Three.js** (3D графика)
- **Tween.js** (Анимации)
- **JavaScript AI** (Логика сложности)
